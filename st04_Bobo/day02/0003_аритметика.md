# Аритметика

Имаме стандартните аритметични операции от математиката:

## 1. Събиране: `+`

**Типове:** `int`, `float`, `str`

```python
x = 5 + 3
y = 0.12 + 9.90
z = "te" + "kst"
```

## 2. Изваждане: `-`

**Типове:** `int`, `float`

```python
x = 5 - 3
y = 0.3 - 1.1
```

## 3. Умножение: `*`

**Типове:** `int`, `float`

```python
x = 3 * 4
y = 12.0 * 0.25
```

## 4. Деление: `/`

**Типове:** `int`, `float`  \*(резултатът винаги е `float`)

```python
x = 10 / 3
print(x)
```

**На конзолата:**

```text
3.3333333333333335
```

```python
y = 2.15 / 1.2
```

**На конзолата:**

```text
1.7916666666666667
```

```python
z = 10 / 2
print(z)
print(type(z))
```

**На конзолата:**

```text
5.0
float
```

## 5. Целочислено деление: `//`

**Типове:** `int`, `float`

```python
x = 10 // 3
print(x)
```

**На конзолата:**

```text
3
```

```python
y = 367 // 100
print(y)
```

**На конзолата:**

```text
3
```

```python
z = 9.0 // 2.0
print(z)
```

**На конзолата:**

```text
4.0
```

## 6. Остатък при целочислено деление: `%`

**Типове:** `int`, `float`

```python
x = 10 % 3
print(x)
```

**На конзолата:**

```text
1
```

```python
y = 367 % 100
print(y)
```

**На конзолата:**

```text
67
```

```python
z = 2.2 % 0.7
print(z)
```

**На конзолата:**

```text
0.1
```

## 7. Степенуване: `**`

**Типове:** `int`, `float`

```python
x = 2 ** 4
print(x)
```

**На конзолата:**

```text
16
```

```python
y = 5 ** 2
print(y)
```

**На конзолата:**

```text
25
```

```python
z = 1.5 ** 3
print(z)
```

**На конзолата:**

```text
3.375
```
