# Логически операции

Едно сравнение, например `5 < 8`, дава стойност от тип `bool` - `True` или `False`. С `and` и `or` можем да комбинираме две условия, а с `not` да обърнем едно условие.

## 1. Логическо И (`and`)

Резултатът е `True` само когато и двете условия са верни. Например един ъгъл е остър, ако е по-голям от 0° и по-малък от 90°.

```python
angle = 45
print(angle > 0 and angle < 90)
```

**На конзолата:**

```text
True
```

```python
angle = 90
print(angle > 0 and angle < 90)
```

**На конзолата:**

```text
False
```

## 2. Логическо ИЛИ (`or`)

Резултатът е `True`, когато поне едно от двете условия е вярно. Например искаме да проверим дали едно число се дели на 2 или на 3.

```python
number = 9
print(number % 2 == 0 or number % 3 == 0)
```

**На конзолата:**

```text
True
```

```python
number = 7
print(number % 2 == 0 or number % 3 == 0)
```

**На конзолата:**

```text
False
```

```python
number = 6
print(number % 2 == 0 or number % 3 == 0)
```

**На конзолата:**

```text
True
```

*и двете условия са верни*

## 3. Логическо отрицание (`not`)

Обръща стойността на условието: `True` става `False`, а `False` става `True`. Например, ако знаем дали една лампа свети, можем да проверим дали е изгасена.

```python
lamp_is_on = True
print(not lamp_is_on)
```

**На конзолата:**

```text
False
```

```python
lamp_is_on = False
print(not lamp_is_on)
```

**На конзолата:**

```text
True
```

## 4. Булеви стойности в `if` и `elif`

`if` и `elif` проверяват дали условието е `True`.

### Пример 1.

```python
number = 8
is_even = number % 2 == 0
print(is_even)
if is_even:
    print("Числото е четно.")
```

**На конзолата:**

```text
True
Числото е четно.
```

Ако сложим `number = 9`, какво ще стане?

### Пример 2. Две сравнения в едно условие

```python
angle = 45
if angle > 0 and angle < 90:
    print("Остър ъгъл")
```

**На конзолата:**

```text
Остър ъгъл
```

### Пример 3. Кое условие е вярно първо?

```python
score = 85
if score >= 90:
    print("Златен медал")
elif score >= 80:
    print("Сребърен медал")
elif score >= 70:
    print("Бронзов медал")
else:
    print("Без медал")
```

**На конзолата:**

```text
Сребърен медал
```
